# Tip-Calculator
The Tip Calculator is a simple Python application that helps users quickly calculate the tip amount, total bill, and how much each person should pay when splitting a bill. It is useful for restaurants, cafes, or any shared expense scenario.


📌 Overview

The Tip Calculator is a beginner-friendly Python project that calculates:

- Tip amount based on percentage
- Total bill including tip
- Amount per person when splitting the bill

It is available in both Command Line (CLI) and Graphical User Interface (GUI) versions.


🚀 Features

- Easy-to-use interface
- Calculates tip instantly
- Splits bill among multiple people
- Error handling for invalid inputs
- GUI built with Tkinter


🛠️ Technologies Used

- Python 3
- Tkinter (for GUI version)

▶️ How to Run

1. Clone the Repository

git clone https://github.com/your-username/tip-calculator.git
cd tip-calculator

2. Run CLI Version

python cli_tip_calculator.py

3. Run GUI Version

python gui_tip_calculator.py


💡 Example

Input:

- Bill Amount: ₹1000
- Tip: 10%
- People: 2

Output:

- Tip: ₹100
- Total: ₹1100
- Per Person: ₹550


⚠️ Error Handling

- Displays error message for invalid inputs (non-numeric values)
- Prevents division errors
